# Task Management Tool – C++

## Project Overview

A simple C++ task management application that allows users to add, view, and delete tasks through a console-based menu.

## Features

* Add a new task
* Set the task completion status
* View all tasks
* Delete a task by title
* Console-based menu
* Linked list data structure

## Technologies Used

* C++
* Object-Oriented Programming concepts
* Linked List
* Dynamic Memory Allocation

## How It Works

The program provides a menu with four options:

1. Add Task
2. View Tasks
3. Delete Task
4. Exit

Each task contains:

* Task title
* Completion status
* A pointer to the next task

Tasks are stored using a linked list.
